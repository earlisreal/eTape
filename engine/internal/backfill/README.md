# Backfill

Coordinates history providers, archive coverage, demand, and merges. Warm horizons end at completed NYSE sessions: daily becomes eligible five minutes after the final data session, while 1m ends at the latest fully closed data-session minute. Explicit archive coverage is queried for missing intervals, so only gaps reach providers; successful empty gaps are persisted, while failures and cancellations are not. Legacy 1m/daily archives infer a whole interval only when every expected trading date, including both boundaries, is represented. Results are clipped and deduplicated to the requested range before archiving; ordered daily fallback advances only after a provider has no in-range bars. Test: `go test ./internal/backfill`.
