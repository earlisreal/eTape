# Execution Core

Broker-neutral lifecycle, gates, routing, reconciliation, and round-trip tracking. The Account projection uses scheduled NYSE close-to-close cycles: closing fills accumulate cycle P&L, open symbols retain partial-exit realization, and a close rebases carried positions to their latest marks. SQLite checkpoints plus fill replay recover the projection; no-checkpoint boots rebase broker positions at zero displayed P&L. Alpaca keeps broker-authoritative `DayPnL` in the display while realized P&L remains local; Alpaca's inactive accounts are excluded from the global day-loss gate. Other broker behavior remains unchanged. Test: `go test ./internal/exec`.
