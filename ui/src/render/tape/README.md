# Tape Renderer

Canvas time-and-sales painter over a bounded tick ring. Inputs: ordered ticks already stamped by the Go UI hub with `none`, `large`, or `exceptional`; output: Aggressor Direction-colored rows with significance styling. Large and Exceptional affect price/size weight only; Exceptional adds a stronger direction tint and edge marker, while timestamps remain normal-weight and neutral stays neutral. The separate low-rate status store powers read-only settings text. Avoid allocations and React updates on the tick path. `tapeLayout.ts` is the shared responsive Price/Size/Time geometry used by the canvas and header: Time appears at 162px and Dockview keeps the panel at 100px minimum. Test: `npm test -- tape`.
