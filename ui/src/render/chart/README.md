# Chart Renderer

Chart controllers, history loading, indicators, sessions, drawings, and primitives. Bar history is shared across panels, while each chart preserves its own logical viewport and scale when older data arrives; visible-range demand may request older history. Main-pane indicators autoscale against visible candles. Latest-tail visibility stays open-ended for live bars and indicators while fetched coverage remains finite. After a symbol/timeframe switch, chart queries omit indicators until the matching `history-ready` event; that barrier clears reused indicator keys and reloads them for the current viewport. Preserve chronological merge/dedupe and controller disposal. Test: `npm test -- chart`.
